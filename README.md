# TrustLedger — AI-Powered On-Chain Reputation System

## Problem
In today's digital world, trust is centralized. Academic records, project experiences, and personal achievements are stored in isolated systems that can be manipulated or lack transparency.

## Solution
TrustLedger is an AI-powered Web3 platform that records user achievements on blockchain and generates a verifiable reputation score.

## Why It Matters
This system removes the need for centralized trust and enables transparent, tamper-proof verification of user capabilities.

## Web3 Component ⭐

**Where it appears**
- User records are stored on blockchain  
- Wallet-based identity using MetaMask  
- Smart contracts manage data submission  

**What it does**
- Ensures data cannot be altered  
- Provides transparent verification  
- Enables decentralized identity  

**Why it is essential**
Without blockchain, users would have to trust centralized systems to store and verify their data. This contradicts the goal of trustless verification and introduces risks of manipulation.
